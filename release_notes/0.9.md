# Spellbreak Modkit 0.9.0

## Highlights

- Added an editable keymap manager in Settings using GUIDE mappings, with primary and secondary shortcut slots.
- Improved shortcut reliability and renamed tab navigation to Previous Tab and Next Tab.
- Added source generation from game `.pak` files and improved Spellbreak pak extraction support.
- Improved Add Files from Sources with a clearer source picker, selected-folder matching, and fixed Select/Browse behavior.
- Added external opening for text/config files from the Mod Manager.
- Fixed texture injection persistence so later clean saves do not undo injected texture changes.
- Cleaned up Settings descriptions and Save/Revert/Close behavior.
- Removed unused addons and generic game-profile flows so the app stays focused on Spellbreak.
- Fixed GDScript reload warnings and added regression coverage for the new workflows.
