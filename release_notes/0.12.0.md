# Spellbreak Modkit 0.12.0

This release expands the editor's asset-cloning and mod-packaging workflows,
hardens binary asset editing, and completes the move to native Godot input and
release infrastructure.

## Highlights

- Added one-click application updates for AppImage, Linux executable, and
  Windows executable releases, including download progress, SHA-256
  verification, safe replacement, backup, and restart.
- Added complete binary asset cloning with companion-file regeneration,
  package identity rewriting, fresh GUID support, and transactional rollback.
- Added unique custom-asset cloning. The packer records clone declarations in
  each mod manifest and patches Spellbreak's `AssetRegistry.bin` automatically.
- Added structured viewing, editing, copy, paste, and undo support for Unreal
  map properties.
- Made import, export, and property names NameMap-backed with correct numbered
  `FName` handling, rename propagation, deletion protection, and missing-name
  save recovery.
- Reworked Base Files into a closable `Ctrl+E` tab with multi-source filters,
  background search, add-to-mod actions, and unique cloning.
- Reworked the Mod Manager into a nested folder tree and added workspace
  manifests for traceable source copies and custom assets.
- Replaced the GUIDE input framework with native Godot actions and editable,
  JSON-backed key bindings.
- Hardened file installation, pak creation, watcher behavior, background-job
  shutdown, symlink handling, and cross-file package-index remapping.

## Requirements

- The .NET runtime is required for binary `.uasset` conversion.
- Python 3 is required for pak creation and bundled Python asset tools.
- ImageMagick is required for texture conversion workflows.
- `umodel` remains optional for mesh and animation previews.

## Downloads

- `sbue.AppImage` — Linux x86_64 AppImage.
- `sbue.exe` — Windows x86_64 executable.
