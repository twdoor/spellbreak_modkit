# Spellbreak Modkit 1.0.0

The first stable release expands cosmetic cloning, adds localization and reusable
batch edits, condenses the interface, and packages the asset tools into single-file
Windows and Linux downloads. These changes include the work since 0.13.0.

## Highlights

- **Clone more cosmetic types.** Clone skins, artifacts, cloudbursts, afterglows,
  emotes, triumphs, cards, badges, and titles with their supported editable
  dependencies. Clones receive independent localization keys and registry
  loading references, while shared game assets keep their original references.
- **Preserve native Blueprint parents.** Native parent metadata now survives
  cloning, registry patching, and portable mod distribution.
- **Translate mod text.** Tools > Localization scans mod text, stores translations,
  and builds language files with English fallback. Normal multi-mod packing
  merges language entries by namespace and key.
- **Reuse batch edits.** Tools > Batch Recipes inspects numeric and boolean
  properties, previews changes, and applies saved recipes with baseline checks
  and recovery backups outside packed content.
- **A more compact interface.** Create and Tools menus consolidate Mod Manager
  actions. Drag sources into your preferred order in Settings; the first
  available source becomes the default in source pickers.
- **Ready-to-run asset tools.** Python, .NET, UE Viewer, and texture tooling are
  bundled. No separate Python, .NET, or ImageMagick installation is needed.
- **Texture previews and imports.** Godot image codecs replace ImageMagick.
  Successful imports clean up their temporary rollback copies instead of leaving
  hidden texture backups alongside assets.
- **Clearer Settings and Diagnostics.** Feature checks show whether tools are
  ready. Technical paths are optional, and custom exporter settings live under
  Advanced. Copy report includes the details needed for troubleshooting.
- **Git project controls.** Fetch, pull, commit, and push run in the background.
  Branches lets you switch local or fetched remote branches and create new
  branches without losing current edits.
- **Optional sync recovery.** Sync replaces local work with the tracked remote
  version. Its confirmation offers an unchecked backup option; enable it to keep
  local commits and files in recovery references. Neither choice changes the remote.

The existing asset editor, widget designer, mesh/animation previews,
mod packing, source browsing, live themes, and portable mod exports remain included.

## Requirements and upgrade notes

- Windows x64 or Linux x86-64, including Fedora. Linux requires glibc 2.38+
  and libstdc++ with GLIBCXX_3.4.26. ARM and Alpine/musl builds are not supplied.
- Git must still be installed to use repository controls.
- Bundled runtimes extract into the writable per-user data folder on first use,
  requiring additional disk space. No runtime downloads or administrator access
  are required.
- Existing settings and sources are retained. An existing custom umodel path
  continues to override the bundled exporter; choose Use bundled to clear it.
- Older `.sb_texture-backup_*` files are not deleted automatically. Remove them
  only when you no longer need their previous texture contents.
- Switching branches requires committed local changes. Creating a new branch
  keeps uncommitted work; publishing it remains a separate action.
- The optional standalone mod-tools ZIP still requires Python 3.10+; it is
  separate from the self-contained desktop editor.
- Legacy Elefrac balance/localization scripts have been removed; use the editor's
  Localization and Batch Recipes workflows. Packaging reference tools remain.

## Downloads

- `sbue.AppImage` — Linux x86-64 AppImage.
- `sbue.x86_64` — Linux x86-64 executable.
- `sbue.exe` — Windows x64 executable.
- `spellbreak-mod-tools.zip` — standalone mod distribution tools and instructions.
- `SHA256SUMS` — SHA-256 checksums for all four downloads.
