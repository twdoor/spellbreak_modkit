# Spellbreak Modkit 0.12.0-beta.1

This is a pre-release build for testing the next editor update. Back up mods and
project files before using it in an existing workflow, and report regressions
with the Diagnostics output when possible.

## Highlights

- Replaced the legacy update checker with semantic-version release management and export-time repository metadata.
- Added one-click in-app updates with download progress, SHA-256 verification, safe executable replacement, backup, and restart. Direct AppImage, Linux executable, and Windows executable assets are supported without ZIP packaging.
- Simplified the editor around its fixed Spellbreak target and centralized bundled tool resolution.
- Added safer staged installs, typed operation results, shared background-service lifecycles, symlink-safe discovery, and lighter file-watcher fingerprints.
- Consolidated installed and save-as pak creation into one transactional packing pipeline.
- Replaced GUIDE with native Godot input actions and JSON-backed editable key bindings.
- Added **Reuse As** for cloning a complete binary asset package under a new asset identity.

## Downloads

- `sbue.AppImage` - Linux x86_64 AppImage.
- `sbue.exe` - Windows x86_64 executable.

## Pre-release note

This build is intended for validation before the stable 0.12.0 release.
