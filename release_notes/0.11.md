# Spellbreak Modkit 0.11.0

## Highlights

- Added a Diagnostics/Health tab for checking paths, tools, writable folders, and Spellbreak profile assumptions.
- Added cleaner operation feedback with expandable logs, retry/copy actions, close controls, and shorter success messages.
- Improved copy/paste for imports, exports, properties, and cross-file references.
- Added editable vector fields for `FVector` / vector structs, including particle distribution values.
- Added a Particle/VFX Inspector that shows particle exports as readable module stacks instead of only raw tree entries.
- Fixed helper completion popups stealing focus from text fields while typing.
- Improved keymap remapping reliability for default and user bindings.
- Improved texture injection, sound import/export, mesh export, and GLB preview reliability.
- Added smooth scrolling to main detail, settings, diagnostics, and diff panels.
- Fixed file dialogs and external file opening so the app remains usable while checking paths.
- Hardened watcher auto-pack on save, including same-size asset saves.
