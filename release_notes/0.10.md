# Spellbreak Modkit 0.10.0

## Highlights

- Added Compare File on Ctrl+K, with secondary keybind support and a cleaner diff view.
- Added fixed-width tabs with hover scrolling for long asset names and better close buttons.
- Added startup file opening so Linux file managers can launch `.uasset` files directly into the editor.
- Made linear/color struct properties editable through a color picker and fixed saving those edits.
- Improved Linux texture export/import reliability and companion file recovery.
- Changed mesh export to GLB as the main format, with reconstructed material textures embedded for Blender and other tools.
- Refreshed mesh preview lighting with a default sky/environment setup.
- Added middle-click mod export to a chosen `.pak` path with a matching `.sig` file.
- Added New Mod creation from an existing `.pak`.
- Hardened the Watch button against rapid toggling.
- Added update checking for newer GitHub releases and a helper for keeping the local Linux `builds/latest` launcher current.

## Downloads

- `linux.zip` - Linux x86_64 export.
- `win.zip` - Windows x86_64 export.
