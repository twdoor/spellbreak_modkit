# Spellbreak Modkit 0.13.0

Create custom skins, edit WidgetBlueprint layouts visually, and distribute independent
mod packs that a separate launcher can combine. This release also adds live theme
editing and Git controls for mod workspaces.

## Highlights

- **Clone skins with their artwork.** Clone the cosmetic blueprint, skin data,
  meshes, materials, color textures, and icons into a mod. Give the new skin its
  own display text and edit its textures through the existing PNG workflow.
  Packing retargets the skin's registry loading bundles to the cloned assets.
- **Edit WidgetBlueprint layouts.** Use the hierarchy, canvas, and inspector to
  preview widgets, drag CanvasPanel children, and edit numeric slot geometry.
  Zoom, pan, embedded widget selection, and asynchronous texture brush previews
  are supported, with changes using the normal undo/save workflow.
- **Navigate large assets more easily.** Browse a lazy export hierarchy, search
  export and property names with multiple terms, or jump to an export with `#1842`.
- **Customize the editor live.** Settings > Edit Theme exposes shared colors,
  text sizes, spacing, padding, and roundness. Changes to the compact theme files
  also reload while the app runs. Built-in file dialogs and tooltips follow the theme.
- **Manage mod Git repositories.** Inspect status, fetch updates, pull with
  fast-forward checks, commit changes, and push from the Mod Manager.
- **Export for separate launchers.** Middle-click a mod and choose Complete
  package or Package + manifest in the built-in browser. The latter produces a
  registry-free content pak, signature, and compact `<name>.manifest.json`.
- **Combine registrations outside the editor.** The standalone helper builds one
  shared registry pak from the enabled manifests and a clean vanilla registry.
  It checks matching pak hashes, rejects duplicate custom targets, and isolates
  skin reference groups across packs. Rebuild when the selected mods change.
- Added Double property editing and fixed editing of automatically supplied
  default properties.

## Using portable packs

Re-export existing packs using **Package + manifest** before combining them.
Keep each manifest beside its matching pak. The launcher must enable the matching
content paks and load the generated registry override; the helper does not install
mods or launch the game. Full instructions are included in `spellbreak-mod-tools.zip`.

Skin creation prepares client content; unlocking/granting cosmetics remains a
server task. The widget designer previews cooked layouts, and material brushes use
an approximate referenced texture rather than reproducing the full game renderer.

## Requirements

- .NET runtime for binary `.uasset` conversion.
- Python 3 for bundled asset tools; Python **3.10+** for standalone mod distribution.
- ImageMagick for texture conversion workflows.
- Optional `umodel` for mesh/animation previews and Git for repository controls.

## Downloads

- `sbue.AppImage` — Linux x86_64 AppImage.
- `sbue.x86_64` — Linux x86_64 executable.
- `sbue.exe` — Windows x86_64 executable.
- `spellbreak-mod-tools.zip` — standalone helper, registry patcher, u4pak, and instructions.
- `SHA256SUMS` — checksums for the downloads.
